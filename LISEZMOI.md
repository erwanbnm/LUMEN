# Lumen

Pour jouer tout de suite : ouvre `dist/lumen.html` dans ton navigateur.

## Ouvrir le projet dans Claude Code
1. Dézippe ce dossier quelque part sur ton PC, par exemple dans `Documents/lumen`.
2. Ouvre Claude Code dans ce dossier :
   - avec l'appli de bureau Claude, lance Claude Code et choisis le dossier `lumen` ;
   - ou, dans un terminal : `cd Documents/lumen` puis `claude`.
3. Écris par exemple : « Lis CLAUDE.md et fais-moi un point sur le projet. »

Claude Code lit automatiquement `CLAUDE.md`. Ce fichier lui explique le projet, les règles et les commandes.
